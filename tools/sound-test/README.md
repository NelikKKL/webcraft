# Проверки звука и стеков матриц

* `QgTest.java` — логика звукового менеджера `qg.java` на JVM (громкости, радиус 16, множитель 0.25 у UI-звуков,
  таймер музыки, пластинки). Нужна заглушка `Sfx` (`SfxStub.java.txt` — переименовать в `Sfx.java`, пакет
  `net.minecraft.client.web`, поставить в classpath раньше настоящего).
* `MatTest.java.txt` — последовательность push/pop логотипа главного меню против раздельных стеков матриц
  (нужны заглушки `GLRaw` и прокси `WebGL2`, см. сам файл).
* Движок Web Audio проверялся в headless Chromium (страница с `extras.js`, синтез всех имён звуков,
  регистрация файлов, воспроизведение, музыка/пластинки, zip-паки со звуками и IndexedDB).

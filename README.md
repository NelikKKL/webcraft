# Minecraft Alpha 1.2.6

> [!WARNING]
> This is not meant to be a pirated version of Minecraft, it just "platform" for playing in Mnecraft Alpha 1.2.6 that allows it to be playable in the browser. If you haven't already, please go [Buy Minecraft](https://www.minecraft.net/en-us/store/minecraft-java-bedrock-edition-pc?tabs=%7B%22details%22%3A0%7D).

This port is based on the original project by skratch. The browser multiplayer implementation is experimental; recent fixes and regression tests are documented in `PATCHES.md`. Run `sh tools/mp-test/run.sh` to execute the JVM-side multiplayer regression suite.
